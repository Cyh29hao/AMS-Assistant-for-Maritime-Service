# 模板来源说明

## 这份说明的目的

这个仓库里包含 Word 合同模板、示例合同、业务样本和版式文件。

这类材料在技术上很好用，但在公开分发时需要明确一件事：

“能放进仓库里做实现”不等于“自动拥有无限制对外再分发权”。

## 当前模板的来源定位

当前 `maritime-service/assets/contract_templates/` 下的模板，更适合被理解为：

- 项目实现样本
- 业务落地样本
- 自动化映射样本

而不是：

- 通用法律模板库
- 面向任意第三方的可自由转载模板集
- 默认可商用的公共条款资产

## 当前仓库中的关联目录

### 模板目录

- `maritime-service/assets/contract_templates/`

### 历史需求材料目录

- `our_requirements/req1/`

这两个目录之间存在实现与样本关系，因此在对外传播时，建议把它们一起审视，而不是只看某一个目录。

## 对外使用时的建议边界

### 可以做的

- 用这些模板演示“系统如何把字段写进 Word”
- 用它们做内部评估、POC、自动化映射验证
- 用它们帮助开发者理解字段对应关系

### 不建议默认做的

- 直接把模板作为“公共免费合同范本”对外提供
- 默认允许第三方抽取模板后单独售卖或二次打包
- 把模板视作已经完成法律审核、适用于所有业务场景

## 如果你准备对外公开更大范围使用

建议补 3 件事：

1. 确认每份模板是否有明确的再分发权限
2. 确认模板中的条款、布局、银行信息、签章区是否已脱敏
3. 必要时替换成你拥有完整权利或已批准公开的模板版本

## 推荐做法

如果未来要把仓库做成更公开、更标准的版本，建议：

1. 保留当前模板用于内部实现参考
2. 另外单独做一套“公开演示模板”
3. 公开模板使用更中性的公司名、字段和条款占位

## 一句话版本

当前模板更像“实施样本”和“业务实现参考”，不是默认放弃权利的公共模板资产。
