AMS Assistant Desktop

给普通用户的本地应用说明

这套应用的目标很简单：尽量让不想碰 Python、不想研究文件结构的人，也能在 Windows 电脑上通过图形界面完成 req1 和 req2，并给 req3 预留统一入口。

你以后主要记住两件事就行：一是打开桌面应用；二是在应用里点按钮。真正的输入 Excel、结果文件、登录态、设置文件，都由应用帮你收纳。

你最先该做什么

  1. 双击启动器，打开 AMS Assistant Desktop。
  2. 先到首页看一眼工作区位置。
  3. 如果你要做合同，去 Req1 出合同。
  4. 如果你要做通关，去 Req2 查通关。

为什么会有“工作区”

因为普通用户最怕“文件一会儿在这里，一会儿又跑到那里”。

所以这套应用会把输入文件、结果文件、登录态、报告，尽量固定到一个你看得见的地方，也就是 工作区。

更新后会不会乱

正常设计下不会。

应用程序本体和用户数据会分开。只要用户数据目录不删，设置、工作区、req2 登录态 就不会因为你换新版应用而消失。

Req1：系统出合同怎么用

第 1 步：打开固定 Excel 在 Req1 出合同 页面，点击 打开输入 Excel。应用会帮你打开固定模板，不需要你自己找文件夹。
第 2 步：填数据 按模板要求填写船名、港口、laycan、费用、货物明细等内容。填完后 保存并关闭 Excel。
第 3 步：一键生成 回到应用，点击 一键生成合同。程序会自动读取刚才那个 Excel，生成 Word 合同和 JSON 摘要。
第 4 步：看结果 如果你启用了自动打开结果目录，生成后会直接弹出结果文件夹。否则点 打开结果目录 就行。

为了让普通用户更容易找，程序还会额外维护一个固定入口文件：00-最新合同.docx。你以后不想翻文件名时，直接找它就行。

req1 最容易出问题的地方不是代码，而是 Excel 里日期格式、模板类型、货物明细漏填。遇到报错，优先检查这些字段。

Req2：自动查通关怎么用

第 1 步：先保存登录态 第一次使用时，在 Req2 查通关 页面点 首次登录并保存登录态。浏览器会打开，你正常登录网站即可。
第 2 步：检查登录态 登录保存后，建议点一次 检查登录态，确认现在这台电脑可以正常复用登录状态。
第 3 步：单票测试 先输入一票提单号、报关单号或箱号，点 查询这一票。这一步是为了先确认网站查询本身没问题。
第 4 步：整表自动回填 打开固定 Req2 Excel，填好业务表，保存关闭，再回到应用点 用当前 Req2 Excel 自动回填。

如果网站返回已放行，程序会把 Excel 里对应行更新成 已通关，并回填 PCS 和 MT。

应用还会生成更新后的工作簿、网站查询报告、文本摘要，方便你人工复核。

同样地，程序也会维护固定入口文件，比如 00-最新更新工作簿.xlsx 和 00-最新网站报告.txt，帮助你总是直接打开最近一次结果。

Req2 浏览器说明

设置页里有一个 Req2 浏览器 选项。

  • auto：优先尝试 Microsoft Edge，再尝试 Chrome，最后尝试 Playwright 自带 Chromium。
  • msedge：强制用 Edge。
  • chrome：强制用 Chrome。
  • playwright：强制用 Playwright Chromium。

普通用户建议先用 auto，因为 Windows 电脑大概率已经有 Edge。

用户数据目录是什么

为了让更新更稳，应用通常会把“会变化的数据”单独保存。

  • 设置文件：保存主题、工作区、浏览器偏好等
  • 工作区：保存 req1/req2 输入和结果
  • 登录态：保存 req2 网站登录态和检查报告

如果你在 release 预览版里看到 user-data 文件夹，这就是它。

最推荐的验收方式

  1. 打开应用。
  2. 进入 Req1 出合同，完成一次“打开 Excel → 填数据 → 一键生成”。
  3. 进入 Req2 查通关，先检查登录态，再做一次单票查询。
  4. 最后做一次整表自动回填，确认更新后的 Excel、JSON 报告、TXT 报告都落到了结果目录。

常见问题

1. 为什么我点完按钮没反应？

先看应用下方的运行日志。大多数问题会在那里写清楚，比如 Excel 没关、登录态失效、字段没填全、或网站查询没返回。

2. 为什么 req2 登录打不开？

先到设置页，把浏览器偏好保留在 auto。如果还是不行，再分别试 msedge 或 chrome。

3. 为什么更新应用后要不要重新设置？

如果用户数据目录保留，通常不用重新设置。真正需要保护的是 settings.json、工作区和 req2 登录态，而不是应用本体文件夹。
