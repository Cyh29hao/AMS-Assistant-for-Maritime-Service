私密业务包

如果你拿到的是一个 .amspack 文件，这一页就是给你看的。它的作用不是把应用变成复杂账号系统，而是把真实模板、真实站点配置和真实业务规则从公开 release 里分离出去，只在需要的人手里解锁。

帮助首页 合同生成中心 通关查询中心 船期与港区矩阵 表格自动同步 私密业务包

它解决什么问题

  • 公开 release 可以继续正常分发。
  • 真实模板和真实配置不需要直接塞进公开仓库。
  • 内部人只需要拿到一个加密包和一串密码，就能解锁完整内容。
  • 以后主程序更新时，本地已经解锁的内容尽量继续保留。

它不解决什么问题

  • 它主要是防路人，不是企业级权限系统。
  • 已经被授权、而且故意要导出内容的人，理论上仍然能拿到本机解锁后的文件。
  • 所以它适合防公开泄露、防误传播、防随手翻文件夹，不适合拿来假装“绝对保密”。

第一次怎么导入

  1. 打开桌面应用。
  2. 进入 设置。
  3. 找到 私密内容解锁。
  4. 点击 导入私密包。
  5. 选择你拿到的 .amspack 文件。
  6. 输入对方私下给你的密码。
  7. 导入成功后，应用会优先读取其中的模板和配置。

如果你自己要做私密包

  1. 打开桌面应用，进入 设置。
  2. 在 制作私密包 区域点击 复制示例到工作区。
  3. 打开工作区里的示例目录，把里面的演示配置替换成你自己的真实模板、真实规则和真实站点配置。
  4. 回到应用，点击 制作私密包。
  5. 选择源目录、保存位置，并设置一串密码。
  6. 生成出的 .amspack 就可以私下发给内部人。

导入后会发生什么

  • 私密内容会被解锁并保存到本地用户数据目录。
  • 合同生成中心会优先使用私密模板和私密规则。
  • 通关查询中心会优先使用私密站点配置。
  • 帮助中心如果有私密版页面，也可以被一并覆盖。

以后更新主程序怎么办

私密业务包默认保存在本地用户数据目录，而不是程序目录里。所以主程序升级时，这部分内容不应该被无谓覆盖。正常情况下，你不需要每更新一次主程序就重新导入一次私密包。

如果要换包或清除

  • 要换新版本私密包：再次点击 导入私密包，新包会覆盖旧包。
  • 要回到公开演示模式：点击 清除私密内容。
  • 如果密码输错：重新导入即可，不会把主程序搞坏。
如果你拿到的是新版本私密包，但导入后效果不像预期，优先检查两件事：一是你拿到的包版本是否正确，二是密码是否输入正确。还不行的话，直接把问题反馈给包的分发者，而不是先怀疑应用本体坏了。
