先看哪一页

  • 合同生成中心：适合要从 Excel 直接生成 Word 合同的人。
  • 通关查询中心：适合要保存网页登录态、查放行状态、回填工作簿的人。
  • 表格自动同步：适合要持续监控源表并把指定字段写入目标表的人。
  • 船期与港区矩阵：当前还是预留入口，但你也可以先看规划说明。
  • 私密业务包：适合内部人解锁真实模板、真实站点配置和完整业务规则。

最短上手顺序

  1. 先点进你要使用的功能页。
  2. 先打开固定输入文件或示例文件。
  3. 按说明完成一次从输入到结果的最短闭环。
  4. 如果遇到别扭的地方，直接发邮件到 cyh29hao@sjtu.edu.cn。
这套帮助文档默认建议用浏览器打开。浏览器对中文编码和页面布局更稳，也更适合给不愿意折腾文件结构的人直接照着做。
