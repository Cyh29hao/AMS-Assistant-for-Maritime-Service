# AMS Assistant Desktop

这一层是给普通用户和交付场景准备的桌面应用壳。

目标不是让用户研究 Python、脚本入口和目录结构，而是把下面这些事情收进一个更顺手的本地 GUI：

- `合同生成中心`
- `通关查询中心`
- `船期与港区矩阵`
- `表格自动同步`
- `私密业务包解锁`

## 这层负责什么

- 提供统一桌面界面
- 提供固定工作区和固定结果入口
- 提供帮助中心和功能级图文说明页
- 保存用户设置
- 保存和复用 `通关查询` 的网站登录态
- 承载 `表格自动同步` 的任务配置和后台监控
- 支持检查更新与自动安装更新
- 提供“私密业务包”导入、清除和状态查看
- 提供“复制示例到工作区 -> 制作私密包”的图形化入口
- 作为普通用户主要接触的入口

## 用户数据怎么保留

桌面版按两层分开：

1. `app/`
   放程序本体
2. `user-data/`
   放用户工作区、自检结果、同步任务、私密包解锁结果等

此外，应用自己的持久设置默认也会写到系统用户目录下的 `AppData/Roaming/AMS Assistant`。

这意味着以后升级 release 时：

- 应用本体可以被替换
- 用户工作区不需要重做
- 登录态、同步任务和私密包不应被无谓覆盖

## 自动更新现在怎么做

目标链路是：

1. 用户在应用里点击 `检查更新`
2. 如果发现新版本，提示是否下载并安装
3. 先显示带进度条的准备窗口
4. 下载最新 release zip
5. 切换到独立更新器继续安装
6. 关闭当前应用
7. 替换 `app/` 目录
8. 保留原有 `user-data/`
9. 自动重新打开新版本

也就是说，用户后续不应该再靠“手动删旧版再解压新版”来升级。

## 私密业务包怎么工作

这是为了把“工具能力公开”和“真实业务内容保留在内部”分开。

### 公开版里保留什么

- 桌面应用本体
- 通用 Excel / Word / 同步引擎
- 帮助中心框架
- 脱敏 demo

### 私密包里放什么

- 真实合同模板
- 真实模板映射规则
- 真实站点配置
- 私密帮助页

### 用户怎么解锁

1. 打开桌面应用
2. 进入 `设置`
3. 找到 `私密内容解锁`
4. 点击 `导入私密包`
5. 选择一个 `.amspack`
6. 输入密码

导入成功后，req1 / req2 会优先读取私密包里的模板和配置。

### 如果你要自己制作私密包

1. 打开 `设置`
2. 在 `制作私密包` 区域点击 `复制示例到工作区`
3. 到工作区里替换成自己的真实模板和配置
4. 回到应用点击 `制作私密包`
5. 选择输出位置并设置密码

这条路径不需要先打开命令行。

### 私密包放在哪里

默认保存在设置目录下的私密包工作区，不跟应用本体混在一起。这样更新程序时更稳，也不需要每次重新导入。

## 如何构建私密业务包

示例目录见：

- [`../private_pack_source.example/README.md`](../private_pack_source.example/README.md)

命令行构建方式：

```powershell
python .\desktop_app\build_private_pack.py --source .\private_pack_source.example --output .\private-pack-dist\demo.amspack
```

## 关键文件

- `app.py`
  桌面应用主界面
- `runtime.py`
  工作区、设置、帮助页、更新检查、自动更新、私密包切换和业务桥接
- `private_pack.py`
  私密包的加密、解密、安装和校验
- `build_private_pack.py`
  构建 `.amspack` 的命令行入口
- `excel_sync_engine.py`
  表格自动同步底层引擎
- `excel_sync_panel.py`
  表格自动同步图形界面
- `build_release.py`
  PyInstaller 打包和 release 预览目录生成
- `release_assets/help/`
  帮助中心和功能说明页

## 打包命令

在仓库根目录运行：

```powershell
python .\desktop_app\build_release.py
```

打包完成后会生成：

- `普通用户体验区-桌面应用版-release预览/`
- `desktop_release_build/AMS-Assistant-Desktop-vX.Y.Z.zip`

## 自检

桌面应用入口支持 `--self-test` 模式，用来确认至少这些东西没有断：

- 应用能初始化工作区
- 合同生成可以跑通一条示例链路
- 帮助中心文件存在
- 表格自动同步 demo 可运行
- 私密包相关能力已打进桌面版

建议始终把“源码能跑”和“打包后还能跑”当成两件事分别验证。
