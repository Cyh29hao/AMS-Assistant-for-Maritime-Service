# AMS Assistant Desktop

这一层是给普通用户和交付场景准备的桌面应用壳子。

它的目标不是让用户研究 `Python`、脚本入口、目录结构，而是把下面这些事收进一个更顺手的本地 GUI：

- `合同生成中心`
- `通关查询中心`
- `船期与港区矩阵`
- `表格自动同步`

其中 `表格自动同步` 现在默认更适合“复制整张表，只排除少数几列”的工作方式，会尽量保留隐藏行、空行和源表结构。

## 现在这层负责什么

- 提供统一桌面界面
- 提供固定工作区和固定结果入口
- 提供帮助中心和功能级说明页
- 每个功能都能单独打开带截图的说明页
- 保存用户设置
- 保存和复用 `通关查询` 的网站登录态
- 承载 `表格自动同步` 的任务配置与后台监控
- 负责打包 release
- 负责检查更新和自动安装更新
- 提供反馈建议入口，方便收集普通用户问题

## 用户数据怎么保留

桌面版现在按两层分开：

1. `app/`
   - 放程序本体
2. `user-data/`
   - 放用户自己的工作区、设置、自检结果等

除此之外，应用自己的持久设置默认也会写到系统用户目录下的 `AppData/Roaming/AMS Assistant`。

这意味着以后升级 release 时：

- 应用本体可以换
- 用户工作区不用重做
- 设置不会因为版本更新自动丢失
- `通关查询` 登录态和 `表格自动同步` 的任务配置也不会因为换版本直接消失

## 自动更新现在怎么做

自动更新的目标是：

1. 用户在应用里点 `检查更新`
2. 如果发现新版本，直接提示是否下载并自动安装
3. 先显示下载准备进度条
4. 下载最新 release zip
5. 切换到独立更新器继续安装
6. 关闭当前应用
7. 替换 `app/` 目录
8. 保留原有 `user-data/`
9. 自动重新打开新版本

也就是说，用户以后不应该再靠“手动删旧版再解压新版”来升级。

现在的更新界面会明确展示：

- 当前百分比
- 当前阶段说明
- 正在处理的文件或动作
- 更新完成后会自动重启的提示

## 关键文件

- `app.py`
  桌面应用主界面
- `runtime.py`
  工作区、设置、帮助页、更新检查、自动更新、业务操作桥接
- `excel_sync_engine.py`
  `表格自动同步` 的底层引擎
- `excel_sync_panel.py`
  `表格自动同步` 在桌面应用内的图形界面
- `build_release.py`
  PyInstaller 打包 + release 预览目录生成
- `release_assets/help/`
  帮助中心和功能级说明页

## 打包命令

在仓库根目录运行：

```powershell
python .\desktop_app\build_release.py
```

打包完成后会生成：

- `普通用户体验区-桌面应用版-release预览/`
- `desktop_release_build/AMS-Assistant-Desktop-vX.Y.Z.zip`

## 自检

桌面应用入口支持 `--self-test` 模式，用来确认至少这些东西没有断：

- 应用能初始化工作区
- 合同生成可以跑通一条示例链路
- 帮助中心文件存在
- `表格自动同步` 的 demo 输入输出可以跑通

如果你要继续扩功能，建议始终把“源码能跑”和“打包后还能跑”当成两件事分别验证。
