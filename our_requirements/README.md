# our_requirements

这个目录主要保存项目历史阶段的原始需求材料与输入样本。

它的定位更接近：

- 内部需求来源
- 历史实现参考
- 方案整理输入

而不是：

- 对终端用户的正式使用入口
- 对外产品文档
- 默认可公开再分发的数据包

## 当前建议

如果仓库继续面向更广泛公开传播，建议对本目录额外做一次审查：

1. 确认原始邮件是否需要保留
2. 确认附件是否已经完成脱敏
3. 确认是否要把真实输入样本替换成演示版材料
