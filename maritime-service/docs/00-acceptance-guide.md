# Acceptance Guide

Use this short guide if you want the fastest possible test.

1. Run the batch file whose name starts with `1-`
2. Open `output/contracts/`
3. Make sure 4 example `.docx` files were created
4. Run the batch file whose name starts with `5-`
5. Make sure every example says `PASS`
6. Run the batch file whose name starts with `2-`
7. Open `examples/workbooks/blank-contract-template.xlsx`
8. Fill column D in the header sheet and fill the cargo rows
9. Save the workbook
10. Drag the workbook onto the batch file whose name starts with `3-`

For the full Chinese acceptance notes, open the file whose name starts with `00-` in this same folder.
