# req2 网页登录版使用教程

这份教程讲的是：让 req2 从“手工把网站结果贴进 Excel”升级成“自动登录网站、自动查询、自动回填 Excel”。

这套新流程的核心入口只有 4 个：

- `11-首次登录并保存req2网站登录态.bat`
- `12-检查req2网站登录态.bat`
- `13-把req2工作簿拖到这里从网站自动查询并回填.bat`
- `14-输入提单号测试req2网站查询.bat`

## 1. 先理解这套流程在做什么

以前的 req2 流程是：

1. 你自己去网站查
2. 你把结果整理到 Excel 的“查询结果”工作表
3. 再用脚本回填

现在的新流程是：

1. 先登录网站一次
2. 脚本把网站登录态保存下来
3. 以后脚本自己拿着这个登录态去网站查
4. 查到结果后，直接回填到 req2 工作簿

所以，新流程的关键变化是：

- 你不再需要手工维护“查询结果”工作表
- 你只需要保证登录态有效
- 工作簿里要有待查询的 `B/L NO.`，并且 `备货` 不是“已通关”

## 2. 第一次使用前要做什么

第一次使用前，建议按这个顺序：

1. 先双击 `0-安装依赖.bat`
2. 等它把 Python 依赖和浏览器装好
3. 再双击 `11-首次登录并保存req2网站登录态.bat`

## 3. 第一次真正登录怎么做

### 第一步

双击 `11-首次登录并保存req2网站登录态.bat`

### 第二步

脚本会自动打开一个浏览器窗口，并进入：

- `https://dp.eptrade.cn/#/`

### 第三步

你就在这个浏览器里，像平时一样正常登录网站。

你不用额外复制 token，也不用点什么“保存”按钮。脚本会一直盯着浏览器里的登录状态，一旦检测到网站已经把 `TOKEN` / `refresh_token` 写进浏览器存储里，它就会自动保存。

### 第四步

保存成功后，你会看到命令行里提示成功，同时这些文件会出现在：

- `output/clearance/site_session/req2_site_session.json`
- `output/clearance/site_session/req2_site_storage_state.json`
- `output/clearance/site_session/req2_site_login_ok.png`

## 4. 如何检查登录态还活着

双击：

- `12-检查req2网站登录态.bat`

它会做的事很简单：

1. 读取你刚才保存的登录态
2. 去请求网站的一个受保护接口
3. 判断这个登录态还能不能用

如果成功，会生成：

- `output/clearance/site_checks/req2_site_check.json`
- `output/clearance/site_checks/req2_site_check.txt`

如果失败，最常见的原因就是：

- 网站登录态过期了
- 你之前没有先跑第 11 个批处理

失败时，直接重新跑：

- `11-首次登录并保存req2网站登录态.bat`

## 5. 如何先查一票，确认网站层已经通了

如果你想先做一个很轻量的验收，不急着拖 Excel，可以先双击：

- `14-输入提单号测试req2网站查询.bat`

然后按提示输入：

- 提单号
- 或报关单号
- 或箱号

脚本会自动判断你输入的是什么类型：

- 纯 18 位数字，按“报关单号”查
- 像箱号格式的，按“箱号”查
- 其他情况，默认按“提单号”查

查询成功后，你会在窗口里看到：

- 实际使用的查询模式
- 是否已放行
- 放行状态文字
- 报关单号
- 提单号
- 箱号
- 件数 `PCS`
- 毛重 `kg`
- 自动换算后的 `MT`

## 6. 如何把网站查询接到 Excel 自动回填

准备一个 req2 工作簿，然后把它拖到：

- `13-把req2工作簿拖到这里从网站自动查询并回填.bat`

脚本会自动做这些事：

1. 打开你保存好的网站登录态
2. 找出 `业务表` 里所有“还没通关”的 `B/L NO.`
3. 去 `pss026` 对应的真实接口查询
4. 把查询结果转换成 req2 需要的结构
5. 自动回填 Excel
6. 生成更新后的工作簿和两类报告

你重点看这些目录：

- `output/clearance/updated`
- `output/clearance/site_query_results`
- `output/clearance/reports`

## 7. 回填时到底填了什么

当前这版网页登录层接的是站点 `pss026 / 海运放行` 对应接口。我已经确认这个接口支持按：

- 提单号
- 报关单号
- 箱号

进行查询。

脚本会优先把站点返回的这些字段用于 req2：

- `cusLetpasStatus`
  用来判断是否已放行

- `pkgNbr`
  回填到 `PCS`

- `cargoGrossWeight`
  网站显示的是 `kg`
  脚本会自动换算成 `MT = kg / 1000`

## 8. 最短上手路径

如果你只想走最短路径，按这 5 步：

1. 双击 `0-安装依赖.bat`
2. 双击 `11-首次登录并保存req2网站登录态.bat`
3. 登录网站，等提示保存成功
4. 双击 `12-检查req2网站登录态.bat`
5. 把 req2 工作簿拖到 `13-把req2工作簿拖到这里从网站自动查询并回填.bat`

做到这里，你就已经真正把 req2 从“手工查网站”推进到“网站自动查 + 自动回填”了。
