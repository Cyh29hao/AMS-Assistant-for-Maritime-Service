# Beginner Guide

This is the short English fallback guide.

1. Run the batch file whose name starts with `2-`
2. Open `examples/workbooks/blank-contract-template.xlsx`
3. Fill the workbook
4. Save it
5. Drag it onto the batch file whose name starts with `3-`
6. Check `output/contracts/`

For the full Chinese tutorial, open the file whose name starts with `01-` in this same folder.
