# 如何验收这套 skill

这份文档是给“验收的人”看的。

如果你不想先研究实现细节，只想快速判断“这套东西到底做出来没有、能不能用”，就按下面做。

## 一句话验收目标

你需要确认三件事：

1. 它能不能生成 Word 合同
2. 它能不能让非技术人员通过 Excel 去生成合同
3. 它生成出来的内容是不是写到了对的位置

## 最快的验收方法

### 方法 A：双击批处理看结果

1. 进入 `maritime-service` 目录
2. 双击 `1-一键生成全部示例合同.bat`
3. 等待窗口执行结束
4. 打开 `output/contracts/`
5. 你应该能看到至少 4 份生成好的合同

预期结果：

- `mu-chuang-362-demo.docx`
- `domestic-logistics-sample.docx`
- `overseas-astar-sample.docx`
- `overseas-rta-sample.docx`

如果这 4 份都出现了，说明最核心的“模板读取 -> 写入字段 -> 输出 Word”已经工作。

### 方法 B：跑自检

1. 双击 `5-一键自检.bat`
2. 看窗口最后有没有出现“通过”字样

预期结果：

- 每个示例 JSON 都显示 `-> 通过`

如果通过，说明脚本已经自动检查了这些关键字段是否真的写进生成文档：

- 合同编号
- 合同日期
- 船名
- 货描
- 部分装港/卸港行

## 进一步验收：人工打开 Word 检查

请人工打开 `output/contracts/` 里的示例文档，重点看下面几处：

### 验收点 1：合同头

检查：

- 合同编号有没有被替换
- 日期有没有被替换
- 船名有没有被替换

### 验收点 2：货描

检查：

- 英文货描有没有写进去
- 中文货描有没有写进去
- 货量总数是不是对的

### 验收点 3：装港 / 卸港 / laycan

检查：

- 装港英文句子位置对不对
- 装港中文句子位置对不对
- 卸港英文句子位置对不对
- 卸港中文句子位置对不对
- laycan 英文日期是不是对的
- laycan 中文日期是不是对的

### 验收点 4：费用条款

检查：

- 装卸率是否被替换
- 滞期费金额是否被替换
- 运费单价是否被替换
- 条款代码例如 `FILO/FIO` 是否对

### 验收点 5：货物明细表

只针对境内模板检查：

- 表格有没有被重建
- 每一行装港 / 卸港 / 数量 / 单位 / 货名是否正确
- 行数是不是和输入一致

## Excel 入口验收

这个验收最重要，因为它决定非技术人员能不能用。

### 验收步骤

1. 双击 `2-一键生成空白Excel模板.bat`
2. 到 `examples/workbooks/` 找到 `blank-contract-template.xlsx`
3. 打开这个 Excel
4. 按 `docs/01-小学生级别使用教程.md` 填一份最简单的测试数据
5. 保存
6. 把这个 Excel 直接拖到 `3-把Excel拖到这里生成合同.bat`
7. 看 `output/contracts/` 是否生成新的 Word 合同

### 通过标准

- 不需要手动敲命令
- 不需要改 Python 代码
- 只靠填 Excel + 拖拽文件就能出合同

1. `1-一键生成全部示例合同.bat` 可以跑通
2. `5-一键自检.bat` 可以跑通
3. `output/contracts/` 中有生成结果
4. 人工打开 Word 后，关键字段位置正确
5. 通过 Excel 拖拽入口能生成一份新的合同

## 如果验收失败，先看哪里

先看：

- `docs/06-常见报错与处理.md`

再看：

- `output/reports/`

因为这里会有每份合同对应的摘要 JSON，方便判断这次到底吃到了什么输入。
