﻿# req2 小学生级别使用教程

这份教程是给“不想看代码、只想把事情做出来”的人写的。

你不用先理解自动化、Agent、API、RPA 这些词。

你只要把它理解成：

1. 有一张业务表
2. 有一张查询结果表
3. 系统帮你把“已经放行”的提单自动回填回去

## 一、这套 req2 到底是干什么的

这套东西是用来做这件事的：

1. 找出业务表里“还没通关”的提单
2. 根据查询结果判断有没有已经放行
3. 如果已经放行，就自动把 `备货` 改成 `已通关`
4. 再把 `PCS` 和 `MT` 填回去
5. 最后给你一份新的 Excel 和一份报告

## 二、你现在手里应该看到什么文件

在 `maritime-service` 文件夹里，你现在会看到几个和 req2 有关的文件：

1. `7-一键生成req2示例结果.bat`
2. `8-一键生成req2空白模板.bat`
3. `9-把req2工作簿拖到这里更新通关结果.bat`
4. `10-一键自检req2.bat`

还有几个目录：

1. `examples/clearance_workbooks/`
2. `output/clearance/updated/`
3. `output/clearance/reports/`

## 三、第一次验收，最简单怎么做

第一次不要拿自己的真实表。

先用示例验收。

### 第一步

双击：

`7-一键生成req2示例结果.bat`

### 第二步

去这个目录看结果：

`output/clearance/updated/`

你会看到一份名字类似：

`req2-demo-case-updated.xlsx`

### 第三步

再去这个目录看报告：

`output/clearance/reports/`

你会看到：

1. `...report.json`
2. `...report.txt`

### 第四步

双击：

`10-一键自检req2.bat`

如果它显示“通过”，说明示例流程已经跑通。

## 四、示例里你应该重点看什么

打开更新后的 Excel。

重点看工作表：

1. `业务表`
2. `执行报告`

### 在 `业务表` 里看什么

你重点看这几列：

1. `备货`
2. `B/L NO.`
3. `PCS`
4. `MT`

你应该能看到：

1. `BA26094SHKK05` 被更新成 `已通关`
2. `BA26094SHKK05` 的 `PCS` 被填成 `4`
3. `BA26094SHKK05` 的 `MT` 被填成 `71.384`
4. `BA26094SHKK01-4` 也会被更新
5. `BA26094SHBT04/05` 不会更新，因为示例里它还是“查验中”
6. `BA26094SHSDK01` 不会更新，因为示例查询结果里根本没有这票

### 在 `执行报告` 里看什么

你会看到系统自动写好的统计结果，比如：

1. 总业务行数
2. 待查询行数
3. 已更新为已通关
4. 原本已通关跳过
5. 仍未放行
6. 找不到查询结果

## 五、如果你想自己做一张真实测试表

### 第一步

双击：

`8-一键生成req2空白模板.bat`

系统会生成：

`examples/clearance_workbooks/blank-clearance-template.xlsx`

### 第二步

打开这个 Excel。

你会看到 4 个工作表：

1. `说明`
2. `业务表`
3. `查询结果`
4. `执行报告`

### 第三步

先填 `业务表`。

最重要的是这些列：

1. `备货`
2. `B/L NO.`
3. `PCS`
4. `MT`

### 第四步

再填 `查询结果`。

你可以把网站上查到的结果，手工整理到这里。

最重要的是这些列：

1. `B/L NO.`
2. `网站通关状态`
3. `是否已放行`
4. `PCS`
5. `MT`

最稳的写法是：

1. 已放行的行，把 `是否已放行` 写成 `是`
2. 没放行的行，把 `是否已放行` 写成 `否`

### 第五步

保存 Excel。

然后把这个 Excel 文件拖到：

`9-把req2工作簿拖到这里更新通关结果.bat`

### 第六步

去这个目录看结果：

`output/clearance/updated/`

脚本会生成一份“更新后的新 Excel”，不会直接覆盖你的原始文件。

## 六、最容易出错的地方

### 错误 1：提单号对不上

如果 `业务表` 和 `查询结果` 里的 `B/L NO.` 不一致，系统会把它记成“找不到查询结果”。

### 错误 2：工作表名字改了

脚本默认认这几个工作表名字：

1. `业务表`
2. `查询结果`

### 错误 3：列名改了

尤其不要乱改这些列名：

1. `备货`
2. `B/L NO.`
3. `PCS`
4. `MT`
5. `网站通关状态`
6. `是否已放行`

### 错误 4：以为脚本会自动登录网站

当前这一版默认不会自己去真实网站登录。

它现在做的是：

1. 读取业务表
2. 读取查询结果
3. 自动回填

所以你当前可以把它理解成：

“半自动版 req2”

## 七、你明天实际验收时建议怎么走

最省脑子的顺序是：

1. 先双击 `7-一键生成req2示例结果.bat`
2. 再双击 `10-一键自检req2.bat`
3. 打开 `output/clearance/updated/` 里的示例结果
4. 人工检查几票提单有没有更新对
5. 再双击 `8-一键生成req2空白模板.bat`
6. 自己做一份测试 Excel
7. 拖到 `9-把req2工作簿拖到这里更新通关结果.bat`
