# 常见报错与处理

## 1. 报错：字段不能为空

这说明你 Excel 或 JSON 里漏填了关键字段。

最常见漏填项：

- `template_key`
- `contract_date`
- `vessel_name`
- `load_port_en`
- `discharge_port_en`
- `demurrage_rate_usd`
- `freight_rate_usd_per_mt`

处理方法：

回到 Excel 的 `头信息` 工作表，看 D 列有没有空着。

## 2. 报错：日期不是合法日期

你很可能写成了：

- `2026/4/3`
- `4-3-2026`
- `2026年4月3日`

正确写法必须是：

- `2026-04-03`

## 3. 报错：`template_key` 不合法

你只能填这 4 个：

- `domestic_forwarder`
- `domestic_logistics`
- `overseas_astar`
- `overseas_rta`

不要自己发明别的写法。

## 4. 报错：`cargo_rows` 第 N 行缺少字段

说明 `货物明细` 工作表某一行没填完整。

必须至少有：

- `loading_port`
- `discharge_port`
- `quantity`
- `unit`
- `cargo_name_en`

## 5. 生成出来了，但内容位置不对

先看：

- 你是不是选错模板了

再看：

- 你是不是把“完整句”只写成了一个港口名

再看：

- 模板文件最近是不是被人改过

如果模板最近被改过，可能需要开发者更新：

- `scripts/contract_template_registry.json`

## 6. 生成出来了，但找不到文件

默认输出目录在：

- `output/contracts/`

摘要目录在：

- `output/reports/`

如果你是双击 `.bat` 运行的，优先去这两个地方找。
